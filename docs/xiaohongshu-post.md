用 DSH 干活最烦的一件事：会话一多，「哪个在跑、哪个跑完没看、哪个在等我授权」全靠翻。

写了个小插件叫「最近会话」，直接长在左侧栏「工作区」上面，用的是官方那套网格，看起来就是原生的：

· 收藏 / 运行中 / 等待你回应 / 完成未读 / 最近活跃，一屏直达

· 整段能收起到一行，标题右边能直接搜

不是浮层、不是新面板，官方会话区一行没改。

装法见评论区👇
