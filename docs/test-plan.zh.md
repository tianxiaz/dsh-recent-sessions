# 测试用例 · 最近会话分区（0.1.2 候选）

> 环境：本地 `link:` 安装的 dsh-recent-sessions，**每次修改后硬刷新**（Cmd+Shift+R）。
> 测试数据：建一个演示工作区，在里面新建 8–10 个会话；其中
> ① 让一个会话触发**授权提示**（跑一条需要审批的命令）→ 黄点；
> ② 让一个会话**跑到完成但不要打开** → 绿点；
> ③ 留一个会话**正在运行**（发一个长任务）→ 蓝点；
> ④ 收藏 3 个会话（行 ☆ 或拖拽）。

---

## A. 基础回归

| # | 步骤 | 预期 |
|---|---|---|
| A1 | 点击分区标题「最近会话」 | 整段收起到一行（36px），只留标题 + 待处理数 + 三个图标；再点展开 |
| A2 | 刷新页面 | 保持 A1 最后的状态 |
| A3 | 清空收藏后刷新（或新装） | 「收藏」默认收起，右侧显示「拖入或点 ☆ 收藏」 |
| A4 | 存在黄点/蓝点/绿点会话时刷新 | 对应分类（等待你的回应/运行中/完成未读）默认展开，「最近活跃」默认收起 |
| A5 | 上述三类都不存在时刷新 | 「最近活跃」默认展开 |
| A6 | 手动展开「收藏」→ 刷新 | 收藏保持展开（选择被记住） |
| A7 | 手动收起「完成未读」→ 刷新 | 保持收起 |
| A8 | 打开另一个会话 | 该行在所有分类里都有选中底色；原选中行取消 |
| A9 | 某分类行数超过上限 | 底部出现「展开其余 N 个会话」；点开后变「收起」，行全部展开 |
| A10 | 点任一会话行 | 打开该会话，分区收起状态不变 |
| A11 | 悬停会话行点 ☆ | 加到收藏，「收藏」分类出现该行；再点取消 |
| A12 | 悬停**官方会话列表**里的行点 ☆ | 同上（官方行也有 ☆） |
| A13 | 把官方会话行拖到分区上 | 加入收藏；拖到「收藏」分类时该组出现 1px 品牌色内描边 |
| A14 | 点分区标题右侧 ⤢ | 打开面板页；面板里能拖拽排序收藏（原有能力） |

## B. 本次新增

| # | 步骤 | 预期 |
|---|---|---|
| B1 | 展开多个分类、连点「展开其余」把行数堆到 20+ | 分区**内部出现细滚动条**（约 5px、半透明），标题行不动；下方「工作区」列表高度不再被继续压缩 |
| B2 | 在 B1 的列表里向下滚到底 | 列表底部出现**渐隐**（内容淡出）；顶部渐隐在非顶部时出现；滚到顶/底后对应渐隐消失 |
| B3 | 滚到中间 → 点标题收起 → 再展开 | 滚动位置恢复到刚才的位置 |
| B4 | 在「收藏」分类里拖动一条收藏到另一条收藏上 | 出现 2px 品牌色插入线，松开后顺序按插入位置调整；**刷新后顺序保持**。拖动经过「收藏」分组时该组才出现淡底 + 1px 描边，**松开/取消/拖出后立即消失**（头部不再有描边） |
| B5 | 把非收藏行拖到某条收藏上 | 该行插入到那条收藏之前（并成为收藏） |
| B6 | 点 🔍，输入 `周报` | 结果**最多 8 条**，行间留 2px；**匹配文字高亮**（品牌色加粗）；**只显示会话标题，不显示所属工作区**（工作区在悬停提示里）；超过 8 条时底部提示「还有 N 条…」 |
| B7 | 搜索框里按 `Enter` | 打开第一条结果（面板/分区状态不变） |
| B8 | 搜索框里按 `Esc` | 清空并退出搜索，回到分类视图 |
| B9 | 输入一个不存在的词 | 显示「没有匹配的会话」 |
| B10 | 把某个会话删掉/归档，使分区里一条会话都没有 | 分区内显示「还没有会话：先在左侧新建一个」 |
| B11 | 制造一个待授权会话（黄点） | 该行右侧显示 **待授权**（而不是相对时间）；提问类显示 **待回答**；悬停行时换成 ☆ · *（待用户测试）* |
| B12 | 用 `Tab` 进入分区后按 `↑` / `↓` | 焦点在分类行与会话行之间上下移动；`Enter` 打开/折叠 |
| B13 | 折叠状态下按 `Tab` / `↓` | 焦点不会跑到隐藏的行里 |

## C. 边界与回归

| # | 步骤 | 预期 |
|---|---|---|
| C1 | 存在已归档会话 | 不出现在任何分类里；若它被收藏过，取消归档后重新出现 |
| C2 | 存在空白新会话 | 不出现在分区里 |
| C3 | 收藏里残留已删除会话 id | 不报错、不显示空行 |
| C4 | 深色 / 浅色主题切换 | 标题、行、滚动条、渐隐、高亮都跟随主题，无白边 |
| C5 | 侧栏收成窄栏（rail） | 分区不渲染（只显示图标栏），展开后恢复 |
| C6 | 分区展开时使用官方搜索 / 会话菜单 / 拖拽排序 | 全部照旧工作，互不干扰 |
| C7 | 面板页（⤢） | 五个分类、选中态、☆、拖拽排序、空状态都正常 |
| C8 | 控制台 | 无红字（尤其无 `slot entry crashed` / `guarded subtree failed`） |

---

## 通过标准

- A/B/C 全部通过，无控制台错误；
- 长列表（20+ 行）时：分区内部滚动、工作区仍可用；
- 刷新后：收起状态、分类折叠、收藏顺序、滚动位置（收起→展开）都符合预期。
