# 测试用例 · 最近会话分区

## 发版前 3 分钟自查（凡是改到"行内 UI"，必须先过这关再发版）

> 背景：0.1.6 因为漏了一行状态声明导致分区消失、又因为多一个收藏标记出现"两个星"，两版都是改完没在真实 UI 里看一眼就发了。以下 8 条是这两天踩过的坑，3 分钟能全部走完。

| # | 检查 | 通过标准 |
|---|---|---|
| 1 | 硬刷新后分区是否还在 | 标题 + 分类正常渲染，**不是**「最近会话加载失败」 |
| 2 | 控制台 | 无 `recent-sessions:` 开头的红字 |
| 3 | 悬停任一行 | 右侧图标各一个：⋯ / 归档 / ☆ / 置顶，**没有重复图标** |
| 4 | 已收藏的行（不悬停） | **只有一个**金色 ★（收藏按钮），没有第二个星形标记 |
| 5 | 点置顶 | 图标由空心变实心、行排到最前；官方列表同一会话也置顶 |
| 6 | 点归档 | 行消失；官方「已归档」里能找到 |
| 7 | 收起 → 展开 → 刷新 | 收起状态、分类折叠、滚动位置都保持 |
| 8 | 状态点 | 收藏 / 最近活跃里的黄、蓝、绿与「等待 / 运行 / 未读」一致 |

**发版闸门**：以上 8 条全过 → 才允许 升版本 → CHANGELOG → tag → 重建索引 → Pages 验证。任何一条不过，先修再发，不要"先发了再说"。

---


> 环境：本地 `link:` 安装的 dsh-recent-sessions，**每次修改后硬刷新**（Cmd+Shift+R）。
> 测试数据：建一个演示工作区，在里面新建 8–10 个会话；其中
> ① 让一个会话触发**授权提示**（跑一条需要审批的命令）→ 黄点；
> ② 让一个会话**跑到完成但不要打开** → 绿点；
> ③ 留一个会话**正在运行**（发一个长任务）→ 蓝点；
> ④ 收藏 3 个会话（行 ☆ 或拖拽）。

## A. 基础回归

| # | 步骤 | 预期 |
|---|---|---|
| A1 | 点击分区标题「最近会话」 | 整段收起到一行（36px），只留标题 + 待处理数 + 三个图标；再点展开 |
| A2 | 刷新页面 | 保持 A1 最后的状态；**分区内的滚动位置也会恢复**（A2 追加：滚到中间后刷新，回来还在原位置） |
| A3 | 清空收藏后刷新（或新装） | 「收藏」收起，右侧显示「拖入或点 ☆ 收藏」；**即使之前手动展开过，清空后刷新也应是收起** |
| A4 | 存在黄点/蓝点/绿点会话时刷新 | 对应分类（等待你的回应/运行中/完成未读）默认展开，「最近活跃」默认收起 |
| A5 | 上述三类都不存在时刷新 | 「最近活跃」默认展开 |
| A6 | 手动展开「收藏」→ 刷新 | 收藏保持展开（选择被记住） |
| A7 | 手动收起「完成未读」→ 刷新 | 保持收起 |
| A8 | 打开另一个会话 | 选中底色**立即**跟到新会话；该会话在 10 分钟内**升到「最近活跃」第一位**（显示「刚刚」），超过 10 分钟后回落到它**真实的最后更新时间**（例：几天前打开过、内容没更新的会话，不会一直显示「40 分钟前」） |
| A9 | 某分类行数超过上限 | 底部出现「展开其余 N 个会话」；点开后变「收起」，行全部展开 |
| A10 | 点任一会话行 | 打开该会话，分区收起状态不变 |
| A11 | 悬停会话行点 ☆ | 加到收藏，「收藏」分类出现该行；再点取消 |
| A12 | 悬停**官方会话列表**里的行点 ☆ | 同上（官方行也有 ☆） |
| A13 | 把官方会话行拖到分区上 | **一开始拖，分区自动收起到一行**，工作区列表拿回高度；拖到标题上时标题变成「松开加入收藏」，松开即加入；松开/取消后分区自动展开回原状 |
| A14 | 点分区标题右侧 ⤢ | 打开面板页；面板里能拖拽排序收藏（原有能力） |

## B. 本次新增

| # | 步骤 | 预期 |
|---|---|---|
| B1 | 展开多个分类、连点「展开其余」把行数堆到 20+ | 分区**内部出现细滚动条**（约 5px、半透明），标题行不动；下方「工作区」列表高度不再被继续压缩 |
| B2 | 在 B1 的列表里向下滚到底 | 列表底部出现**渐隐**（内容淡出）；顶部渐隐在非顶部时出现；滚到顶/底后对应渐隐消失 |
| B3 | 滚到中间 → 点标题收起 → 再展开 | 滚动位置恢复到刚才的位置 |
| B4 | 在「收藏」分类里拖动一条收藏到另一条收藏上 | 出现 2px 品牌色插入线，松开后顺序按插入位置调整；**刷新后顺序保持**。拖动经过「收藏」分组时该组只出现**极淡的品牌色底（8%）+ 120ms 过渡**，无描边；**松开/取消/拖出后立即消失** |
| B5 | 把非收藏行拖到某条收藏上 | 该行插入到那条收藏之前（并成为收藏） |
| B6 | 点 🔍，输入 `周报` | 结果**最多 8 条**，行间留 2px；**匹配文字高亮**（品牌色加粗）；**只显示会话标题，不显示所属工作区**（工作区在悬停提示里）；超过 8 条时底部提示「还有 N 条…」 |
| B7 | 搜索框里按 `Enter` | 打开第一条结果（面板/分区状态不变） |
| B8 | 搜索框里按 `Esc` | 清空并退出搜索，回到分类视图 |
| B9 | 输入一个不存在的词 | 显示「没有匹配的会话」 |
| B10 | 把某个会话删掉/归档，使分区里一条会话都没有 | 分区内显示「还没有会话：先在左侧新建一个」 |
| B11 | 制造一个待授权会话（黄点） | 该行右侧显示 **待授权**（而不是相对时间）；提问类显示 **待回答**；悬停行时换成 ☆ · *（待用户测试）* |
| B12 | 用 `Tab` 进入分区后按 `↑` / `↓` | 焦点在分类行与会话行之间上下移动；`Enter` 打开/折叠 |
| B13 | 折叠状态下按 `Tab` / `↓` | 焦点不会跑到隐藏的行里 |
| B14 | 悬停一条收藏行 | ☆ 左边出现 **↑ 移到最前**；点击后该行跳到「收藏」第 1 位，**刷新后保持** |
| B15 | 悬停非收藏行 | 不出现 ↑（只有 ☆）；面板页（⤢）里收藏行也有同样的 ↑ |
| B16 | 给「最近活跃」里的某条点 ☆ | 它**仍留在最近活跃**（行尾出现 ★），同时出现在「收藏」；取消收藏后 ★ 消失 |
| B17 | 让一个「等待你的回应」会话出现在最近 5 条内 | 最近活跃里也会出现它（纯时间列表），状态点颜色照旧 |

## C. 边界与回归

| # | 步骤 | 预期 |
|---|---|---|
| C1 | 存在已归档会话 | 不出现在任何分类里；若它被收藏过，取消归档后重新出现 |
| C2 | 存在空白新会话 | 不出现在分区里 |
| C3 | 收藏里残留已删除会话 id | 不报错、不显示空行 |
| C4 | 深色 / 浅色主题切换 | 标题、行、滚动条、渐隐、高亮都跟随主题，无白边 |
| C5 | 侧栏收成窄栏（rail） | 分区不渲染（只显示图标栏），展开后恢复 |
| C6 | 分区展开时使用官方搜索 / 会话菜单 / 拖拽排序 | 全部照旧工作，互不干扰 |
| C7 | 面板页（⤢） | 五个分类、选中态、☆、拖拽排序、空状态都正常 |
| C8 | 控制台 | 无红字（尤其无 `slot entry crashed` / `guarded subtree failed`） |
| C9 | 浏览器窗口高度压到约一半（约 450–500px 的侧栏） | 工作区仍能看到 5–6 行；「最近会话」内部滚动；再压到极矮（约 250px 侧栏）时应**只剩标题一行**，工作区仍可见 |
| C10 | 窗口全屏 / 拉高到 1000px+ | 「最近会话」最高 420px（约 11 行），工作区拿到剩余高度；比例随侧栏高度线性变化，不跳变 |
| C11 | 人为制造一次崩溃（临时在代码里 throw） | 左栏不空白：出现提示 + 「重新加载」，下面仍是官方会话列表 |
| C12 | 收藏一个「等待你的回应」的会话 | 「收藏」里该行显示**黄点 + 待授权/待回答**，与它在「等待你的回应」里完全一致；取消收藏后仍黄点 |
| C13 | 收藏一个「完成未读」的会话 | 「收藏」和「最近活跃」里都是**绿点**；点开该会话后回到灰点（未读状态被清除） |
| C14 | 同一会话同时出现在收藏 / 等待 / 最近活跃 | 三处**颜色、文案、悬停提示完全一致**（状态只由会话决定） |
| C15 | 在一个不属于任何工作区的目录（如 `/tmp`）用 CLI 跑一个会话，跑完（空闲）后硬刷新 | 该会话**不出现在「最近会话」**（含搜索）；仍在官方列表的「未分组」里 |
| C15′ | 同一类未分组会话**弹出授权 / 待回答** | 它出现在「等待你的回应」；回答后（变空闲）自动消失 |
| C15″ | 同一类未分组会话**正在运行**或**完成未读** | **不出现**在「运行中 / 完成未读」里（只有"等你回应"才出现）；处理完同样不显示 |
| C16 | 在某个工作区里新建会话并说一句话 | 该会话正常出现在分区里（说明过滤只针对未分组） |

## D. 会话行动作（0.1.6）

| # | 步骤 | 预期 |
|---|---|---|
| D1 | 悬停任一会话行 | 右侧依次出现 **⋯ / 归档 / ☆ / 置顶** 四个按钮（时间/标记让位） |
| D2 | 点「⋯」 | 弹出菜单：置顶、收藏、移到最前（仅收藏行）、分隔线、归档、复制会话 ID；点菜单外或 Esc 关闭 |
| D3 | 菜单里点「置顶」 | 该行右侧出现**官方图钉图标**，且在所有分类里**排到最前**；下方官方列表里同一会话也同样置顶 |
| D4 | 再点「取消置顶」 | 图钉消失，排位恢复 |
| D5 | 点「归档」 | 该行从分区消失；官方列表的「已归档」里能看到它 |
| D6 | 菜单里点「复制会话 ID」 | 剪贴板拿到 `session-…` 形式的 ID |

## 通过标准

- A/B/C 全部通过，无控制台错误；
- 长列表（20+ 行）时：分区内部滚动、工作区仍可用；
- 刷新后：收起状态、分类折叠、收藏顺序、滚动位置（收起→展开）都符合预期。
