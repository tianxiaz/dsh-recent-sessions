# 发布宣传逻辑（分阶段执行）

> 一句话定位（所有渠道固定不变）：**像官方「工作区」一样长在 DSH 左侧栏里的「最近会话」**。
> 两个记忆点：**同一套网格的原生感**、**每个会话行都有 ☆**。
> 三个证据：截图、和同类方案的区别、可回退（禁用即恢复官方侧栏）。

前提（已完成）：市场条目已合并、0.1.3 已发、README / 落地页 / 分享卡 / 文案全部就位。

---

## 阶段 0 · 动笔前先定"谁"

| 受众 | 在哪 | 他们在意什么 | 用哪条卖点 |
|---|---|---|---|
| 已经在用 DSH 的人 | Discord、GitHub Discussions、你的群 | "能不能立刻解决我翻会话的问题" | 装完就好用 + ☆ 一键收藏 |
| 关注 AI 工具的人 | X、即刻、V2EX | "这东西长什么样、和别的有什么不一样" | 原生分区（不是浮层）+ 截图 |
| 搜技术方案的开发者 | 掘金、知乎 | "怎么实现的、靠不靠谱" | 接管外壳 + 复刻官方网格 |

**顺序逻辑**：先打"已经在用的人"（转化最高、反馈最快）→ 再打"围观的人"（曝光）→ 最后打"搜索的人"（长尾）。

---

## 阶段 1 · 冷启动（D0，约 1 小时）

目标：让已经有 DSH 的人当天就能装上。

1. **GitHub Discussions（不用权限，先发）**
   - `deepseek-ai/deepseek-harness` → Discussions → New discussion → Show and tell；
   - 标题：`Recent Sessions — a left-sidebar section on the official Workspaces grid`；
   - 正文：`docs/announce.md` 的"短版英文" + 市场链接 + 图。
2. **awesome-dsh-plugin Discussions**：同一条内容，换个标题。
3. **你的 DSH 群 / 微信群**：中文短版 + 整窗图，结尾问一句"要我帮装吗"。
4. **Discord**（等有角色后补）：`#showcase`/`#plugins`，一条即可。

**D0 结束标准**：至少 1 个渠道有回应（点赞/回复/提问）。

---

## 阶段 2 · 扩散（D1–D3）

目标：让"还没装 DSH 但关注 AI 工具"的人看见。

5. **X**：一句卖点 + 分享卡 + `#DeepSeek #DSH`；
6. **即刻**：中文短版 + 整窗图，语气口语化；
7. **V2EX · 分享创造**：标题务实（`给 DSH 写了个「最近会话」侧栏插件`），正文讲"为什么不做浮层"，2–3 段即可；
8. **掘金长文**（D2–D3 发，写 1 小时）：《我给 DSH 左侧栏加了一个「最近会话」，做法是接管官方外壳》——问题 → 同类方案 → 单占位槽限制 → 接管 + 复刻网格 → 截图 → 安装。

**D3 结束标准**：至少一篇长文/帖子被收藏或转发；市场条目开始出现安装量。

---

## 阶段 3 · 沉淀（D4–D7）

目标：把流量变成"可被搜索到"的资产。

9. **知乎**：自问自答《如何评价 DSH 的「最近会话」插件？》，放长文精简版；
10. **公众号**（你已有的号）：把掘金长文改成故事版；
11. **GitHub 仓库**：把用户高频问题写进 README 的 FAQ（装不上/冲突/回退）；
12. **issue 沉淀**：每个真问题开一个 issue，标签 `question` / `bug`，公开回答。

**D7 结束标准**：搜索"DSH 最近会话"能搜到我们的仓库或文章。

---

## 阶段 4 · 复利（D8 之后，长期）

13. **每次发版发一条短播报**（模板在 `docs/announce.md`），保持存在感，不刷屏；
14. **两周一帖**：挑一个真实使用场景（"我怎么用它管 20 个会话"）而不是重复功能；
15. **看反馈定 0.2.0**：呼声最高的需求才做（多语言、云同步、置顶……先别自己加）。

## 渠道取舍（为什么是这些）

| 渠道 | 用 | 理由 |
|---|---|---|
| Discord / GitHub Discussions | ✅ | DSH 用户密度最高，是"决定要不要装"的现场 |
| V2EX 分享创造 | ✅ | 中文独立开发者集中，容忍自荐，反馈质量高 |
| 掘金 / 知乎 | ✅ | 搜索长尾，文章寿命长，能持续带来安装 |
| 即刻 / 小红书 | ✅（轻） | 曝光快、转化低，适合图文冲一波 |
| 公众号 | ✅（私域） | 沉淀 + 复用长文 |
| 微博 / HN / 付费投放 | ❌ | 噪音大或受众不匹配，ROI 不明 |

## 衡量与调整

| 指标 | 看什么 | 怎么用 |
|---|---|---|
| Star 增量 | 每天记一次 | 判断哪个渠道真的带来人 |
| 市场条目下载/浏览 | awesome-dsh-plugin 条目页 | 判断"装"的转化 |
| Issue / 提问 | 数量与类型 | 决定下一版做什么 |
| 渠道互动 | 点赞/回复/收藏 | 48h 无互动 → 换标题角度重写，**不要在同渠道重复发** |

**每周 15 分钟复盘**：哪个渠道带来最多安装 → 下周加倍投入；哪个渠道只有浏览没有安装 → 检查落地页/安装指引。
