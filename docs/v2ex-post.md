## 帖子正文（中文，30 天后可直接用）

**标题**

```
给 DSH 写了个「最近会话」侧栏插件，做法是接管官方侧栏外壳
```

**正文**

```
最近用 DSH 干活，会话一多，「哪个在跑、哪个跑完了还没看、哪个在等我授权、我常回访的是哪几个」就得翻半天，所以写了个插件：最近会话。

它不是浮层，也不是独立面板，而是像官方「工作区」一样长在左侧栏里的一个分区，用的就是官方那套网格（36/34/32/28px）：

· 收藏 / 运行中 / 等待你的回应 / 完成未读 / 最近活跃，一屏直达，黄蓝绿状态点
· 每个会话行都有 ☆，一点即收藏（官方列表里的行也有）
· 悬停动作和官方一致：⋯ 更多 / 归档 / 收藏 / 置顶；⋯ 菜单里还有「移到最前」「复制会话 ID」
· 置顶按分类生效 —— 在最近活跃置顶只影响最近活跃，收藏有自己的手动顺序，取消置顶会回到原位
· 整段能收起到一行，标题右边能就地搜索（高亮命中、回车打开第一条），还支持 ↑↓ 键盘浏览
· 官方会话区一行没改：搜索、会话菜单、拖拽排序、归档筛选全部照旧

技术上有点意思的部分：DSH 的 sidebar 和 sidebar.workspaces 都是单占位槽，插件没法"在旁边插一节"。所以这个插件是接管了 sidebar 外壳（禁用官方 ui-sidebar），然后把官方 Workspaces 浏览器原样渲染回去；另外给侧栏整体加了一层 error boundary，插件自己挂了会退化成「提示 + 官方会话列表」，不会让左栏空白。

还在迭代，欢迎拍砖：
仓库 https://github.com/tianxiaz/dsh-recent-sessions
市场 https://awesome-dsh-plugin.com/p/tianxiaz/dsh-recent-sessions/
（与 huangxp12 / whybebabo 的最近会话插件互斥，同一个面板 id，二选一）

DSH 版本要求 ^0.2.1-rc.5。
```
