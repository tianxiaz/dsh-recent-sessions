# 傻瓜式发布步骤（照着点就行）

> 全程约 25 分钟。**只用两个文件**：
> - 图 A：`docs/social-preview.png`（1280×640 分享卡）
> - 图 B：`docs/preview-desktop-light.png`（整窗示意）
> 文案全部在下面，直接复制。

---

## 第 0 步：发之前 2 分钟检查（3 项）

1. 打开 <https://awesome-dsh-plugin.com/p/tianxiaz/dsh-recent-sessions/> —— 能看到标题、描述、仓库链接；
2. 打开 <https://github.com/tianxiaz/dsh-recent-sessions> —— About 有描述、Website、topics；
3. 把「图 A」「图 B」两个文件放在桌面，等下每个渠道都要用。

---

## 第 1 步：DSH 官方 Discord（约 5 分钟）

1. 打开 <https://discord.gg/4MrtZUhpxg>，点 **Accept Invite** 进服务器；
2. 看左侧频道列表，找名字像 `#plugins`、`#showcase`、`#show-your-work`、`#community-showcase` 的频道，点进去；
   - 如果找不到这类频道，进 `#general` 发，但**只发一条**；
3. 点消息输入框，粘贴下面这段（英文）：

```
Built a small DSH plugin: Recent Sessions — a section in the left sidebar built on the official Workspaces grid (favorites / running / waiting-for-you / unread / recently active).

Highlights: a one-click ☆ on every session row, collapse the whole block to one line, search in place, official browser untouched.
Market: https://awesome-dsh-plugin.com/p/tianxiaz/dsh-recent-sessions/
Repo: https://github.com/tianxiaz/dsh-recent-sessions
(Incompatible with the recent-sessions plugin from huangxp12 / whybebabo — pick one.)
```

4. 点输入框左边的 **＋** → **Upload a File** → 选「图 A」→ 按 **Enter** 发送；
5. 发完就停，**不要连发、不要 @everyone**。

---

## 第 2 步：awesome-dsh-plugin 的 Discussions（约 3 分钟）

1. 打开 <https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/discussions>；
2. 点右上 **New discussion**；
3. 类别选 **Show and tell**（或名字最接近"展示插件"的那个）；
4. 标题填：
   ```
   dsh-recent-sessions — Recent sessions on the official Workspaces grid
   ```
5. 正文粘贴（英文，和 Discord 同一段即可，末尾加一行仓库链接）：
   ```
   A section in the DSH left sidebar built on the official Workspaces grid: favorites / running / waiting-for-you / unread / recently active, with a one-click ☆ on every session row, one-line collapse and in-place search.

   Market: https://awesome-dsh-plugin.com/p/tianxiaz/dsh-recent-sessions/
   Repo: https://github.com/tianxiaz/dsh-recent-sessions
   (Incompatible with the recent-sessions plugin from huangxp12 / whybebabo — pick one.)
   ```
6. 点 **Start discussion**；想插图就把「图 A」直接拖进编辑框。

---

## 第 3 步：你的 DSH 群 / 微信群（约 2 分钟）

1. 打开群聊 → 点输入框；
2. 粘贴（中文），**先发文字**：

```
给 DSH 写了个小插件「最近会话」：像官方「工作区」一样长在左侧栏里的分区——收藏 / 运行中 / 等待你的回应 / 完成未读 / 最近活跃一屏直达。
亮点：每个会话行都有 ☆ 一点即收藏；整段可收起到一行；标题右侧就地搜索；官方会话区一行没改。
市场：https://awesome-dsh-plugin.com/p/tianxiaz/dsh-recent-sessions/
仓库：https://github.com/tianxiaz/dsh-recent-sessions
（与 huangxp12 / whybebabo 的最近会话插件互斥，二选一）
```

3. 再发「图 B」（整窗图）；
4. 加一句自己的话更自然，例如「有问题直接在这条下面说，我尽量当天回」。

---

## 第 4 步：X / Twitter（约 3 分钟）

1. 打开 <https://x.com/compose/post>；
2. 粘贴（英文，X 有字数限制，这段刚好够）：

```
Recent Sessions for DSH: a section in the left sidebar on the official Workspaces grid — favorites, running, waiting-for-you, unread, recently active.

One-click ☆ on every row · fold to one line · search in place.

https://awesome-dsh-plugin.com/p/tianxiaz/dsh-recent-sessions/
#DeepSeek #DSH #plugin
```

3. 点 **Add photos** → 选「图 A」→ **Post**。

---

## 第 5 步：即刻（约 3 分钟）

1. 打开即刻 → 右下 **＋** → 选「动态」；
2. 粘贴（中文短版，同第 3 步那段）；
3. 添加图片 → 选「图 B」→ 发布。

---

## 第 6 步（次日再做）：V2EX / 掘金

- **V2EX**：<https://www.v2ex.com/go/create> → 节点选 **分享创造** → 标题 `给 DSH 写了个「最近会话」侧栏插件` → 正文用中文短版 + 补 2–3 句"为什么做"（例如"看不惯浮层方案"），插图 B；
- **掘金**：写长文，标题《我给 DSH 左侧栏加了一个「最近会话」，做法是接管官方外壳》，结构：问题 → 同类方案对比 → 单占位槽的限制 → 接管外壳 + 复刻 36/34/32/28 网格 → 截图 → 安装。

---

## 第 7 步：发完 30 分钟内做 3 件事

1. 每个渠道把自己的帖子**收藏/置顶**（Discord 可以点消息右上角 → Pin）；
2. 守着评论，常见问题直接回（模板在 `docs/launch-day.md` 的"首日回复模板"）：
   - 装不上 → 索引源要 https、别带 `#`，刷新「发现」；
   - 侧栏没变化 → 硬刷新；
   - 会不会改坏侧栏 → 官方会话区没动，禁用即回退；
   - 和另一个最近会话插件冲突 → 二选一；
3. 当天结束记一笔：各渠道链接 + 有没有人问、问了什么。

---

## 红线（别做）

- ❌ 同一个群/服务器连发多条；
- ❌ 去 DSH 官方仓库的 issue 区发广告；
- ❌ 用"最强 / 最好用 / 颠覆"这类词；
- ❌ 承诺还没做的功能（云同步、npm 版、第二语言界面之外）。
