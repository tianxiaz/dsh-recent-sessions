# 即刻发布（5 分钟）

**入口**：即刻 App（或 <https://web.okjike.com/>）→ 右下 **＋** → 选「动态」

**配图**：
- 竖版封面：<https://tianxiaz.github.io/dsh-recent-sessions/docs/xiaohongshu-cover.png>
- 或整窗图：<https://tianxiaz.github.io/dsh-recent-sessions/docs/preview-desktop-light.png>

**文案**（直接复制）：

```
给 DSH 写了个插件「最近会话」：像官方「工作区」一样长在左侧栏里。

收藏 / 运行中 / 等待你回应 / 完成未读 / 最近活跃 一屏直达；每个会话行都有 ☆；悬停有 ⋯ 归档 收藏 置顶；整段能收起到一行，标题右边就地搜。

不是浮层、不是新面板 —— 接管官方侧栏外壳后，把官方会话区原样渲染回去，官方功能一行没改。

市场：https://awesome-dsh-plugin.com/p/tianxiaz/dsh-recent-sessions/
```

**注意**：
- 即刻动态里链接有时不自动展开，发完自己在评论区补一条纯链接；
- 不要带一堆标签，1–2 个就够（如 `#AI工具`）；
- 发完守着前 30 分钟的回复。
